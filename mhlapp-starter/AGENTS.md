# MHLApp Agent Rules

Antes de implementar cualquier tarea:

1. Leer `PROJECT_BIBLE.md` completo.
2. Trabajar únicamente sobre el alcance solicitado.
3. No cambiar schema de Supabase sin proponer una migration y recibir aprobación.
4. No usar las tablas legacy para features nuevas.
5. No usar service_role en browser ni commitear secretos.
6. Ejecutar `npm run typecheck` y `npm run build` antes de cerrar una tarea.
7. Informar archivos modificados, cómo probar y pendientes.
8. Si la base real contradice una suposición, detenerse: no inventar columnas.
