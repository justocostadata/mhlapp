# Supabase migrations

La base MHL ya existe y contiene el schema fundacional creado/migrado antes de este repo.
No ejecutar una recreación automática sobre producción.

A partir de este repo, cada cambio nuevo de schema debe guardarse aquí, revisarse y ejecutarse conscientemente.
Próximas migrations previstas (no creadas aún): `match_registrations`, `match_payments`, `match_staff` y campos configurables del motor de partido.
